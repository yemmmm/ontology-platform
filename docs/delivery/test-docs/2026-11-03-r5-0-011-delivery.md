## 实现范围

- Task 可选 process_evaluation，默认关闭；Host 四个命令提供开关、显式成果提交、独立 worker 执行及汇总。使用说明见 [v5 README](../../../modeling_team/v5/README.md#可选过程评价r50-011)。
- 三类观察点绑定来源、产物精确版本、范围、零/一/多单元、准则版本及摘要、实际模型配置；实际整合另绑定本体修订。固定身份重复复用，显式复评新增记录，历史记录保留取代关系及版本适用性。
- CQ/切片仅只读材料；整合要求对应修订的治理读取及实际模型正文。引用快照非原子备份，无法取得原文时保留证据缺口；已保存合法材料可复用。没有建立历史模型回放系统。
- 独立原生上下文及工具范围，只读获准来源和产物，不挂载生产团队工具/记忆/隐藏验收包，不接收生产输入。结果写诊断对象，不注入生产或正式验收。
- 停用持久化截止 epoch，取消未启动记录，保留在途自然收尾；并发 worker 按身份加锁；未知在途由原 ExecutionManager 对账，不重新启动。显式纠错保留原绑定及每次执行证据。
- 原任务 pause/stop/金额预算准入及计量复用，采用 acceptance 模型，独立 process_evaluation 用途。原账本计价单元和原始用量证据单列；未知成本不补零，外部 Host 不计入任务预算。不创建预算，不增加建模轮次。
- 0–4、未验证、不适用分开；必需维度全部合格且没有关键差距才能满意。不提供统一总分，不跨不可比绑定算涨分。JSON/Markdown 版本化汇总保留三类覆盖分母，暂停不是生产完成，晚到结果保留终态。
- 首期是显式 Host 提交及独立 worker 命令，无常驻评分调度器。未从聊天、节点、回合结束自动推断业务阶段；生产不等待评分。
