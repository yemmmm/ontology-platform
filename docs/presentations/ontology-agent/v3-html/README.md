## 技能与素材

按 [Frontend Slides](https://github.com/zarazhangrui/frontend-slides/blob/main/SKILL.md) 的 HTML 演示方式制作，并结合 `frontend-design` 的页面设计指导。使用已有风格与已经确认的内容方向，保留固定 1920×1080 画布，内嵌字体、图片、样式、交互和讲稿。

`vendor/frontend-slides/viewport-base.css` 保留该技能的完整固定画布基础样式。封面复用 `../deck/assets/cover-network.png`；字体使用 Noto Sans CJK SC 与 Noto Serif CJK SC 的新字符子集。许可已内嵌到 HTML，发布 ZIP 附第三方许可。

## 使用

默认完整显示内容。方向键／空格翻页，`S` 切换分步演讲，`A` 展开本页，`G` 打开目录，`N` 显示当页演讲稿，`F` 全屏。手机支持横向滑动翻页，画布保持 16:9；横屏更适合阅读。

点击政策对照、模型元素等按钮查看教学演示；所有互动均在浏览器本地运行，不调用业务系统。`E` 开启正文编辑，`Ctrl+S` 下载修改后的 HTML。修改后的文件不会自动同步 PDF 或内容审阅稿。

单个 HTML 可离线打开。PDF 展开所有内容和 FAQ，保留默认教学事实，便于静态阅读。

## 重建

```bash
uv run --with fonttools python v3-html/build.py
```

在上级演示工作目录运行。`build.py` 保存逐页内容，`deck.css` 定义样式，`deck.js` 实现交互。构建会生成离线 HTML、逐页演讲稿、内容审阅稿与页序清单；`speaker-notes.md` 保留为演讲稿的同内容入口。PDF 使用 Chromium 的打印样式导出，画布为 1920×1080，无页边距。
