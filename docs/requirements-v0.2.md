# Ontology Platform v0.2 需求文档

## 版本背景

当前版本记为 `v0.1`。`v0.1` 已实现本体元数据管理、图谱实体/关系管理、基础校验、JSON 导入导出接口、MCP 查询工具、Agent Test 接口，以及可运行的 React/Vite 管理界面。

`v0.2` 的目标是把 MVP 从“能创建和演示”推进到“能日常编辑、审阅、迁移数据并更好支持 Agent 使用”。本需求清单仅记录 P0 和 P1，不包含健壮性、安全性、权限体系等需求。

## 范围说明

- 本文档为候选需求清单，需确认后再进入实现。
- P0 表示 v0.2 必须完成，否则版本目标不成立。
- P1 表示强烈建议完成，可按工期裁剪。
- 暂不考虑用户账号、RBAC、组织租户、生产级密钥管理、审计日志、限流、防攻击等安全与健壮性需求。

## P0 需求

### P0-1 前端补齐编辑能力

**目标：** 前端应支持编辑已有项目、本体、类、属性定义、关系类型、实体。

**说明：** 后端已有对应 PATCH 接口，但当前 UI 主要支持创建和删除，无法在浏览器中完成日常维护。

**验收标准：**

- 可在 UI 中修改项目名称/描述。
- 可修改本体名称、描述、状态。
- 可修改类名称、描述、别名、父类。
- 可修改属性定义的名称、类型、描述、必填、多值、枚举值。
- 可修改关系类型的名称、描述、别名、源类、目标类、反向名称。
- 可修改实体名称、别名、属性 JSON。
- 编辑成功后列表和详情立即刷新。

### P0-2 前端支持导入导出

**目标：** 在 UI 中提供本体导出和导入能力，覆盖已有 HTTP API。

**说明：** v0.1 已有 `/export` 和 `/import` 接口，但 UI 暂未暴露操作入口。

**验收标准：**

- 可导出当前本体的 schema、entities、relations 为 JSON 文件。
- 可选择 JSON 文件导入到当前项目。
- 导入完成后自动刷新项目下的本体列表。
- 导入前展示目标项目和文件名，避免误操作。

### P0-3 图谱管理增强：搜索、过滤与详情上下文

**目标：** 提高实体和关系维护效率，避免图谱数据增长后只能查看少量列表。

**验收标准：**

- 实体列表支持按关键词搜索。
- 实体列表支持按类过滤。
- 关系列表支持按实体或关系类型过滤。
- 点击实体后可查看直接入边、出边和关联实体摘要。
- 图谱视图与列表选择状态联动。

### P0-4 建立后端基础测试集

**目标：** 为 v0.2 的核心行为建立最小自动化回归保障。

**验收标准：**

- 新增 `backend/tests/`。
- 覆盖本体元数据服务的创建、更新、删除关键路径。
- 覆盖实体属性校验：必填、未知字段、类型、枚举。
- 覆盖关系校验：源/目标类兼容和不存在实体。
- 提供 `cd backend && uv run pytest` 可运行的测试说明。

## P1 需求

### P1-1 本体版本发布工作流

**目标：** 激活当前已存在的 ontology version 数据模型，让本体可形成明确版本快照。

**验收标准：**

- 可从当前本体 schema 发布一个版本。
- 实体和关系创建时可关联当前版本 ID。
- UI 显示当前本体版本状态和当前版本 ID。
- 暂不要求跨版本自动迁移。

### P1-2 MCP 工具浏览器

**目标：** 在前端新增独立 MCP 工具调试页，与 Agent Test 分离。

**验收标准：**

- 可选择工具：`search_entities`、`get_entity`、`find_related_entities`、`validate_entity`、`explain_entity`。
- 表单根据工具展示必要参数。
- 可查看原始 JSON 请求和响应。
- 请求使用当前选中的本体上下文。

### P1-3 Agent Test 结果可追溯

**目标：** 让 Agent Test 更适合调试本体和图谱上下文。

**验收标准：**

- Agent Test 页面展示工具调用顺序、参数和每步结果摘要。
- 展示最终 prompt preview、graph context、warnings、errors。
- 支持一键复制问题、答案、上下文 JSON。

### P1-4 图谱视图交互升级

**目标：** 改善当前简单 SVG 图谱视图的可读性。

**验收标准：**

- 支持缩放和重置视图。
- 支持按类或关系类型高亮。
- 节点详情中展示 class、aliases、properties。
- 边详情中展示 relation type 和 properties。

## 暂不纳入 v0.2

- 完整用户系统、RBAC、组织租户。
- 生产级安全加固和密钥生命周期管理。
- RDF/OWL/SHACL 作为主模型。
- 向量搜索、embedding 索引。
- 自动从代码、文档、日志抽取知识。
- 推理引擎、复杂规则引擎、多 Agent 编排。
