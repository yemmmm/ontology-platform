# v5 Agent 通信、材料交接与回合边界澄清

日期：2026-10-29。当前代码基线：`5631e2c`。

本次根据用户关于 Agent 通信、交接材料按需读取及 busy 排队含义的问题，核对需求和
当前源码。本文是合同澄清与最小实现建议，不代表已实现 v5 同伴通信、任务卡或自动调度，
不改变现有运行及授权，不启动新建模。

## 1. 通信可以承载交接，交接状态仍由原流程管理

建议的同伴通信入口同时覆盖普通对话、署名协作请求及获准的工作／成果交接。
交接消息说明交给谁、当前范围、材料入口和期望下一步；工作卡引用同一请求及材料，
不重复保存整份候选、模型或报告。本人计划仍由本人维护，其他 Agent 可添加署名请求。

通信负责保存、路由及送达；原流程继续管理工作责任、内容版本、实际处理和结果引用。
消息入队、送达、读取、处理完成及依赖满足分别记录，不能因发送成功就认为对方已读或
已完成交接所要求的工作。不增加固定的接单／确认握手；对方可直接处理并回复结果。
若某步骤已有正式候选、应用或验收合同，引用方式仍进入该合同，不借普通消息绕过。
独立验收只接收获准的冻结交接，不开放生产与隐藏验收之间的任意对话。

## 2. 消息正文与材料分开，按需读取

推荐复用既有 `text` 与 `material_refs` 的分离方式：

| 部分 | 含义 | 接收方式 |
| --- | --- | --- |
| 消息正文 `text` | 沟通、用途、当前问题、希望对方处理什么及定位提示 | 作为下一适用回合的输入 |
| 材料引用 `material_refs` | 原文、候选、决定、计划、报告等的实际内容入口 | 先提供材料身份、固定版本和简短用途，再由接收方按需展开 |
| 已有正式正文引用 `body_ref` | 原入口所要求的完整正式内容对象 | 解析后进入原内容校验和处理，不以导航摘要替代 |

例如 A 请 B 校验某定义，只在正文说明定义范围、疑点及期望反馈；定义正文、来源、相关
决定作为材料引用。B 可以先读目标定义及其直接依据，发现依赖后继续展开，不必把项目
所有材料装入上下文。实际需要的材料仍须读取；没有读取的内容保持未读，不能仅凭摘要
宣称已经审阅全部范围。

正文、引用或混合方式由 Agent 按任务选择，不新增按大小强制转换门。目录交接固定本次
文件集合，清单与原文分别支持继续读取；正式交接固定内容版本，后续修改不静默替换。
引用必须能在接收者环境中实际读取，发送不可访问的宿主路径不算完成材料交接。

当前 v5 的 `read_material(material_id, offset, limit)` 已按授权 manifest 读取文本，
offset／limit 为字符范围，返回 SHA256、总字符数及 `next_offset`。这证明已有按需分段
读取底座；现入口尚未实现 Agent 新产物向另一 Agent 的材料发布、授权及消息挂接。
后续应补齐这段接线，不能仅把路径塞进消息，也不需要另建通用文件服务。

## 3. busy 排队等待的是一次原生 turn

“当前原生回合自然结束”指一次 Codex `turn/start` 发起的完整执行，运行时报告
`turn/completed` 后才能在后续回合投递新输入。一次 turn 可以包含多次模型请求、
工具调用、工具结果后的继续推理及多段输出。

```text
B 当前 turn：推理 → 工具 1 → 继续推理 → 工具 2 → 最终输出 → turn/completed
A 的新消息：           入队并持久保存 ───────────────────────→ 下一适用 turn 投递
```

| 观察到的边界 | 是否因此允许投递给 B |
| --- | --- |
| 一段文字／输出 item 结束 | 否，原生 turn 可能仍在继续 |
| 一次工具调用结束 | 否，模型可能继续处理工具结果 |
| 整次原生 turn 结束 | 可以在下一可运行且匹配工作范围的回合投递 |
| 当前业务阶段／整个任务完成 | 不要求等到此时 |

若 Agent 把整个阶段放在一个 turn 内完成，实际等待会延续到该阶段结束；原因是该 turn
尚未结束，不是队列以业务阶段为门。任务拆分应允许有意义的有界回合，不用普通消息
steer／interrupt 正在执行的原生 turn，也不引入按时钟强制切断。

排队表示消息现在已被保存为 queued，发送方可立即得到入队回执；不是阻塞发送方等待
B 完成工作，也不表示 B 已看见。busy 结束只是允许后续投递的边界，还需目标工作单元
可运行并由编排器推进。当前 v5 已退出的人工等待 run 仍需显式 CLI resume，没有后台
自动唤醒；同伴自动路由／推进仍未接入。
