# 切片一：安装与验收 v1
I1. 安装工单是安排并记录一次资产安装工作的工作记录，不等于资产本身。安装工单→安装资产，表示此次被安装的资产。工单的施工完成时刻表示施工结束，不等于验收通过时刻。
I2. 验收记录是对安装工单的一次验收结论及其作出时刻的记录；验收记录→安装工单。结论分为正式通过、有条件通过、拒绝。一次工单可有多次记录，记录之间不是互相覆盖。正式通过须有授权验收人的签署；有条件通过只允许试运行，不启动正式保障；拒绝亦不启动。
I3. 某资产的首次正式验收时刻，是其安装工单所关联的有效签署且结论正式通过的验收记录中最早的结论时刻。没有满足条件的记录则该时刻未知，不能用施工完成、有条件通过或单纯已签署代替。材料没有给出签署撤销机制，不能编造。
I4. 正式验收后可进入合同保障判定，但正式验收本身不证明合同覆盖有效；还须按故障发生时刻检查合同覆盖和暂停状态。跨切片规则由父级保留。
I5. 安装按期率是观察期内有明确约定完成时刻、且已正式通过的安装工单中，首次正式通过时刻不晚于约定完成时刻的数量，除以同一集合的总数。观察期按首次正式通过时刻落入 [期初, 期末) 判断；分母为零时结果未知。没有明确约定完成时刻者不进分母；施工完成时间不替代正式通过时间。该指标不是所有派发工单的完成率。
