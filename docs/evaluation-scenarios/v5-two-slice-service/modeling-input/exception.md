# 跨切片例外、来源状态与未知 v1
E1. 应急临时服务许可是对尚未正式验收资产的某个故障提供一次临时返修服务的授权记录；许可→故障事件。仅有合同覆盖不等于已有许可。许可须有服务主管签署，且只对指定故障有效，不推广到资产全部历史或其他故障。
E2. 获该许可可以开展临时返修服务，但不把有条件通过改为正式通过，不把合同保障判定改为真，不纳入受合同保障的响应达标率分母；临时服务可单列数量，本资料未规定收费或响应目标。
E3. 现场安全隔离是实施安装或返修作业前必须满足的业务条件；正式验收、合同覆盖或临时服务许可均不能豁免安全隔离。隔离是否完成无证据时保持未知，不自动确认允许作业。
E4. 所有上述定义与指标均为本参考包的 v1 口径。没有给定小时的小数舍入、异常倒置时刻修正或签署主体权限名单，不补造；这些未知不掩盖已明确规则。撤回一份材料只撤回其来源支撑，不自动断言原规则为假；须核对其他当前资料再决定模型表达。
