# 切片二：故障与返修履约 v1
R1. 故障事件是对某资产一次问题发生的记录，故障事件→安装资产。返修工单是为处理故障而执行的服务工作，返修工单→故障事件；同一故障可重开原工单，重开不创造新的故障事件。问题重现另记新故障时，与旧故障不同，不能只按同一资产自动合并。一个故障可以关联多张返修工单。
R2. 返修受合同保障，当且仅当故障发生时已达到该资产首次正式验收时刻，并存在在该发生时刻有效且未处于暂停区间的合同覆盖。判定时点是故障发生，不是派单、修复或关闭；发生恰好在覆盖失效时刻不受该覆盖保障。首次正式验收时刻或故障发生时刻未知，则保障结论未知，不能记成不保障。
R3. 服务响应是针对返修工单的首次有效人工响应，自动回执不计。响应耗时=首次有效人工响应时刻−工单创建时刻；缺任一时刻则未知。合同标准响应目标为4小时，达到目标含等号；不能从“尚未响应”推断耗时为零。响应不是到场、恢复或关闭。
R4. 延迟记录是一张返修工单等待的时间段及已确认原因；延迟记录→返修工单。原因未确认的记录保留未知，不自动归为客户等待。解决净耗时=最终解决时刻−工单创建时刻−已确认客户等待时间段的并集时长；只扣与[创建,最终解决]交集，重叠段不重复扣。物流等待、内部等待、原因未知均不扣。重开后以最后一次最终解决为终点，中间暂时解决不作为最终终点；缺最终解决时刻则净耗时未知。
R5. 响应达标率的观察集合：工单创建时刻在[期初,期末)、受合同保障、且有可计算首次人工响应耗时的返修工单；分子为其中响应耗时≤4小时者，分母为该集合数量。无响应或时间不全者另报未知数量，不混入已知集合；分母为零则达标率未知。是否关闭不决定响应达标。
