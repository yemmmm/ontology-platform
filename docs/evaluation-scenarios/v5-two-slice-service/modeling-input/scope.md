# 售后安装与返修：范围及共享语义 v1
来源：Host 编制的公开工程参考资料，2026-10-31。不是客户制度，不继承 industrial-service-v3 的隐藏业务真值。
本次完整范围为两个业务切片：安装验收、返修履约。模型表达业务定义、关系、条件、计算口径和明确未知，不创建任何具名业务实例、SQL/API 映射、SHACL 或自动规则执行。
S1. 服务现场是安装设备的物理地点；安装资产是已安装的单件设备。资产安装于现场，方向资产→现场，只表示安装地点，不表示所有权。资产编号仅在同一客户范围唯一；不据此把不同客户的同号资产合并。本场景不另展开客户管理。
S2. 服务合同是服务方与客户约定资产服务范围和期限的协议。合同覆盖是某合同适用于某资产的有时间界限的业务关联记录，与合同或资产本身不同；覆盖→合同、覆盖→资产。覆盖有效区间为 [生效时刻, 失效时刻)，失效为空表示尚未约定终点，不表示已失效。合同为暂停状态时，覆盖即使在区间内也不能据此认定返修受合同保障。恢复后的历史暂停区间仍不受保障。
S3. 所有时间采用 Asia/Shanghai；持续时长用实际经过小时，不按工作日或营业时间。时间未知与实际为零不同。一个资产可以有多次安装工作及多次故障，未给定上限；不得凭名称推断一对一。
S4. 安装切片与返修切片共享同一资产、现场、合同覆盖以及正式验收含义；业务切片不决定 Ontology 数量。父级保留跨切片规则和未分配范围。没有给出合同费用、库存、人员考核、数据权限制度和自动续约规则，保留范围外。
