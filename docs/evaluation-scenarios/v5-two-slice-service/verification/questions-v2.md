# 冻结独立语义标准：两个业务切片 v2
范围是完整原始资料，不是检查命名相似度。只能从实际受治理模型取得业务答案；原材料用于判定忠实度，生产笔记不能补模型缺项。对关系必须展开实际端点，不凭自然语言方向陈述直接判通过。每题给出实际读取、资源 IRI、版本、得到的答案及未支持处。已知遗漏必须失败，真实未知按材料判断。
1. 资产／现场区别、安装关系方向和非所有权；客户范围编号唯一性未扩大为全局唯一。
2. 合同覆盖作为有时限业务关联及其到合同／资产的实际端点；[生效,失效)和失效空值含义。
3. 合同暂停区间不受保障，恢复不回溯抹除；时间采用上海时区和实际经过小时，未知不等于零。
4. 安装工单区别于资产、工单指向资产；施工完成不等于验收通过，不发明一对一。
5. 验收记录到工单的端点、三种结论、授权签署及多次记录保留。
6. 首次正式验收的最早合格记录规则；有条件通过、拒绝、施工结束、单纯签署均不能替代；缺合格记录未知。
7. 安装按期率观察窗口、明确约定、正式通过集合、≤边界、分母零未知，不能用施工完成替代。
8. 故障到资产、返修工单到故障的实际端点和身份区别；重开原单与新故障区分、不发明故障到工单一对一。
9. 合同保障同时依赖正式验收、故障发生时点的覆盖和暂停；失效端点排除，关键时刻未知仍未知。
10. 人工首次响应排除自动回执；从创建计时、6小时含等号，响应与到场／恢复／关闭有区别。
11. 延迟记录端点及原因确认；只扣客户等待与执行区间交集的并集，其他／未知原因不扣。
12. 解决净耗时按重开后的最终解决，不用暂时解决；终点缺失未知。
13. 响应达标率创建窗口、合同保障、已知可计算集合、未知另报、分母零，以及关闭状态不决定达标。
14. 当前材料已撤回 E1/E2，临时许可只保留可定位历史，准入／签署／故障范围不得继续冒称当前获确认规则；也不能断言实际业务不存在许可。
15. 当前临时服务的保障归属、目标、收费均为待确认，不继续用旧许可条款给当前合同响应率补分母结论；仍忠实保留其他当前来源的合同保障规则。
16. 安全隔离同时约束安装和返修，正式验收／合同／许可不能豁免，完成证据缺失不默认为可作业。
17. 不补造舍入、时刻纠错、权限名单、收费、SQL/API、业务行实例或其他范围外规则。
18. 两切片在实际图共享同一资产、合同覆盖和正式验收含义，整体条件相容；局部模型不能用相互矛盾定义各自通过。
