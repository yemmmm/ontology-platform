# v5 组合合同参考场景

日期：2026-10-30。用于 T04.2／T05.2 的公开、非盲参考场景，来源为
[方法设计 §18](../../delivery/designs/2026-10-26-ontoweave-modeling-methodology-design.md#18-大型业务的递归推进与覆盖推演)
的安装／返修／配件补偿共享额度例子，以及已验证的“临时许可不等于正式完成”表达情境。

这是获准建模测试的独立人工材料，不是工业服务原客户资料的补充真值。金额与年度补充是本场景的
显式测试政策，不能回写成客户确认。脚本仅复制这些静态材料及记录真实事件，不生成业务真相。

- `modeling-input/`：首次生产可见的全部业务材料。只建立一般业务含义与规则，不创建业务行实例。
- `host-input/`：启动前固定的署名测试补充，按真实问题分阶段转送；未来额度版本只在 source-revise 时公布。
- `verification/`：生产前冻结的公开检查标准。评价只读原始资料、实际治理模型和固定阶段原件，不能修生产。

四个责任单元不等于四个 Ontology。十个逻辑引用用于核对共同澄清的范围，不要求启动十个 Agent。
首个版本和来源变化后的版本分别保留；预算为同一任务 3 元，失败、重试和独立评价沿原账本。
该场景的成功不替代客户业务盲测、任意多层递归、独立重复性或净降耗证明。

追加的[总览消费三题](verification/overview-questions.md)在 revision 5 交接后、总览生成前冻结，
只检验同范围的导航消费；与首次生产前冻结的十二题分别记录，不回改主标准。
