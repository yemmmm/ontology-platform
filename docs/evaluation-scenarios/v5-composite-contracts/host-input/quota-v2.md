# 共享年度额度，版本 2

Source ID: v5-composite-quota-v2
作者：test-scenario-owner；本参考场景后续明确变更，首次建模时不可预读。

本场景后续版本将同一合同、同一已确认合同年度的共享上限从 100000 元变为 120000 元。
新上限只适用于这次明确变更之后的参考场景版本，不回写成旧版本从来就是 120000。
三类既有占用加本次拟批准金额的口径、同合同／同年度范围、不超过的包含边界及局部条件仍不变。
紧急临时可用许可仍不豁免额度或正式核验条件；甲／乙类年度定义及未给出的未知也不因本次变更改变。

原验证情境仍仅为规则验证，不创建业务实例：30000、40000、50000，以及合计 119999.99、120000、120000.01。
原始版本和先前结论必须保留，当前模型、认知和相关摘要不得继续把 100000 当作本版本上限。
