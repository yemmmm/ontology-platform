# 业务范围与共同口径

Source ID: v5-composite-scope-v1
作者：Host 参考场景设计者，2026-10-30；仅用于获准测试。

本场景有甲类、乙类服务合同；费用分为安装、返修、配件补偿。四个建模责任分别是合同／年度定义及
安装、返修、配件补偿局部含义。项目整合方另负责共享额度、三方组合及 parent-scope.md 的未分配整体命题。
不得因为四个局部提案齐全，就默认整体范围齐全。

“合同年度”起算和期末归属对两类合同都尚未确认。由合同／年度责任单元提出一项共同问题，其他单元
引用同一未决含义，不各自猜测或重复提问。Host 后续只转送启动前固定的署名测试补充。年度口径是本轮
必须澄清的范围；只得到甲类答复不能说乙类也确认了，乙类等待时无关定义可以继续。

十个逻辑引用为：甲安装占用、甲返修占用、甲补偿拟批准、甲年度归属、甲三项合计，以及对应五个乙类引用。
它们都使用共同的合同年度含义；不是十个真实业务行、十个具名合同或十个必须创建的本体。

金额统一以元计，使用本资料定义的占用金额；不需要税费折算、汇率或真实账务记录。没有提供合同／工单／
客户实例、数据库或 API 映射、权限政策、核验通过标准、付款与退款规则；这些保持未知，不得猜造。
