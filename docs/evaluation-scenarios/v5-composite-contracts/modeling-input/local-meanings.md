# 三个局部含义

Source ID: v5-composite-local-meanings-v1

安装费用占用：合同年度内因安装产生、已按本场景口径确认的占用金额。
返修费用占用：合同年度内因返修产生、已按本场景口径确认的占用金额。
配件补偿拟批准金额：本次拟批准的配件补偿金额，核验本次申请时计入共享额度条件；不等于已经支付。

三者属于不同局部含义，却按 quota.md 的同合同／同年度共享规则组合。各自局部条件成立，不推出合计条件成立。
局部条件的具体审批标准未给出；验证情境把“局部条件成立”作为前提，不由样例金额反推新的单项上限。
金额语义依赖合同与年度口径。年度未确认不妨碍表达这些一般定义，但不能提前给出对应合同的年度分摊结论。
