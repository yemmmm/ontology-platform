# 共享年度额度，版本 1

Source ID: v5-composite-quota-v1
同一合同、同一已确认合同年度，安装、返修和配件补偿共用 100000 元上限。
核验本次申请的额度条件时，计入该年度三类既有占用及本次拟批准金额，合计不得超过上限。
“不超过”包含恰好等于上限；不是三类各有一个独立额度，不能只检查本次申请或各单元自身。
额度条件满足不代替其他局部条件；没有依据时不声称最终付款／业务全面合规。

以下仅为规则验证情境，不是待写入的业务实例：三方局部条件都成立时，安装既有占用 30000、返修既有
占用 40000、本次补偿拟批准 50000；以及合计分别为 99999.99、100000、100000.01 的情境。
合同年度未知时不能替甲／乙类猜测年度归属，也不能把不同合同或不同年度的金额混在一起。
