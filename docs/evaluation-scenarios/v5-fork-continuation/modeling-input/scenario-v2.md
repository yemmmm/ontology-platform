# Fork 续建公开工程材料 v2

本材料是同一公开 Host 工程 fixture 的显式补充，不是客户业务确认。

- 保留演示设备与演示核验记录两个既有类别：设备不是某台设备；核验记录的存在不代表核验已经通过。
- 补充设备编号的含义：它是标识演示设备的文本值，编号格式及唯一性未规定。就本有界表示测试，将该补充整合进原设备类别的语义定义，不另建同义设备类或编号类别。
- 补充“记录针对设备”关系：方向为演示核验记录 → 演示设备，表示记录的核验对象属于设备类别；关系本身不表示通过、合格或完成，不声明基数。
- 不新增业务实例。核验标准、人员、期限、数据库映射以及编号格式／唯一性仍为未知。

必须复用 fork 后的现有两个类别，不能重复创建类别规避现有资源身份解析。
