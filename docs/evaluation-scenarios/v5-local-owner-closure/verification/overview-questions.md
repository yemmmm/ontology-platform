# 导航生成前冻结：分层实际模型消费

本附加范围与原单元闭环六题分开；公开有界工程参考，不是客户盲测。只读当前实际模型与由其生成的导航，不能用生产笔记补模型事实。

1. 导航是否可沿整体业务→专题→具体定义逐层深入，而不是只有平面分节？层数随内容，跨专题的共享额度／年度定义引用相同真实资源；不得制造多份互相冲突的当前定义。
2. 各层是否忠实保留同合同／年度共享合计、包含边界、父级正式完成与临时许可区分及关键未知？上层不可吞掉决定性限定；精确判断应能沿引用取得实际定义，摘要缺陷不能用原材料补过。
3. 导航生成是否仅有获准实际目标／只读能力，没有生产候选、工作笔记或隐藏题泄露；当前模型 revision、可见范围和限制准确，生成与使用记录可追溯？此题不替代来源撤回、权限漂移或跨 run 复跑验证。
