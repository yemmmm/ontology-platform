## 业务定义

1. 现场（Service Site）是安装设备以提供服务的物理地点。
2. 安装资产（Installed Asset）是已安装、用于提供服务的单件设备。
3. 安装资产安装于现场：方向为“安装资产→现场”，含义是设备的物理安装位置。
4. 两个概念不同：现场是地点，资产是设备；安装关系不表示所有权。
