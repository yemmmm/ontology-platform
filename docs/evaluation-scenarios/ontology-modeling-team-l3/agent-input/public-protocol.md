# Public L3 platform protocol

Only the separately launched Platform Protocol Agent receives this document, the
approved candidate, and a run-local scope object. The candidate authorizes semantics;
the Protocol Agent owns conversion to Modeling Items and every platform call.

Use only the enabled generic ontology-platform MCP tools. Read health, modeling and
workspace context; create a Build Session; acquire the supplied Ontology lease; create
schema/resources including an executable Shape; submit immutable schema and instance
Batch candidates with exact `dry_run` then `apply_atomic` transitions; and submit one
separate invalid instance as dry-run only. Run managed validation and reasoning, issue
a complete scoped generic query/read-model operation for the published C->B->A path,
Current Draft, and named explicit unknown, then checkpoint, complete, and reread the
Build Session.

The deterministic `/opt/mechanics-contract.json` defines canonical request envelopes,
IDs, workspace revisions, lease renewal/checkpoint bodies, and receipt parsing. It
never supplies ontology semantics. Correct only JSON/schema/IRI/reference/call-order
mechanics. Return workspace, scope, Batch-content, concurrency, or semantic conflicts
to the coordinator without changing semantics. Never write plaintext keys into files.
