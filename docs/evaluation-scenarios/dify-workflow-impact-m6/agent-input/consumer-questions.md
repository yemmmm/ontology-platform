# Required consumer outcomes

The applied model must let a read-only consumer determine:

- which concrete published C behavior B currently consumes;
- whether the output used before and after C's newer release represents continuous or discontinuous
  business meaning; and
- what B is known to do when C completes without a scoring value.

Answers must come from public semantic facts. Do not invent a value when the supplied material does
not uniquely determine it.
