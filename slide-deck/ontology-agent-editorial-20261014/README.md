## 使用

解压 ZIP 后，在现代浏览器中打开 `index.html`。演示 HTML 内嵌字体和第 6 页图片，可离线播放。

- 方向键、空格、PageDown／PageUp：逐步展示和翻页。
- `A`：展开当前页。`N`：备注与来源。`F`：全屏。
- `E`：编辑正文。`Ctrl+S`：下载编辑后的 HTML。
- 目录、章节首页“返回目录”及底部“目录”按钮支持跳转。
- 第 5 页保留“首次响应／恢复服务”切换。

第 6 页为概念示意图片，图中文字不支持逐项编辑；原始图片位于 `assets/business-understanding-methods.png`。其他正文保持网页文本编辑方式。PDF 为静态阅读版本。

本体相关优势说明方法的侧重点，实际收益需要业务验证。自动推理仍标为后续能力，教学关系图与案例不代表真实平台运行结果。业务数据继续保留在外部数据库。

`source-draft.md` 为历史文字草稿，页码沿用原稿；当前页序以 `revised-outline.md` 和本目录演示为准。`references/` 为沿用的项目来源快照。第三方字体与演示基础样式许可见 [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt)。
