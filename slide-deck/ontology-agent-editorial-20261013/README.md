## 操作

- 目录页点击章节标题跳转；章节首页点击“返回目录”，或使用底部控制栏“目录”按钮返回。
- `→`、空格或 PageDown：下一步；本页显示完成后进入下一页。
- `←`、PageUp：上一步。
- `A`：展开本页全部内容。
- Home／End：第一页／最后一页。
- `N`：查看当前页原稿讲解备注和来源；Esc 关闭备注。
- `F`：切换全屏。
- `E`：编辑正文；点击文字修改，再点击左上角“完成编辑”。
- `Ctrl+S`：下载修改后的 HTML；文字修改也会保存在当前浏览器中。
- 第 5 页可点击“首次响应／恢复服务”，切换 SLA 教学指标。
- 移动鼠标会显示底部控制栏；支持滚轮和横向滑动导航。

## 内容与风格

采用暖白底、森林绿强调、宋体封面与重点引语、无衬线正文。新增页面使用概念关系图、分工表、架构图、泳道图和案例关系图，结合原稿讲解备注补充必要解释文字。

第 11、20 页明确标注自动推理是后续能力，当前阶段不提供。工业服务关系、问题回答、Context Query 结果和 SQL/API 应用路径均按教学示意呈现，不冒充真实运行、数值结论或验收结果。未确认的计时起点、暂停、时区、空值与适用合同口径继续保留为未知。

模型表达与业务执行职责分开：语义层保存定义、关系和映射，业务行保留在外部数据库，实际动作仍需外部系统授权和执行。
